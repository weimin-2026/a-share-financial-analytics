# 代码讲解（高中生版）

## 从哪里开始

`app.py` 像一本书的目录：侧边栏决定打开哪一页，页面再调用 `src/` 中的普通函数。这样页面展示和数学计算不会混在一起。

## 每个文件做什么

- `src/config.py`：保存股票代码、名称、缓存目录和免责声明。
- `src/data.py`：向 AKShare 请求数据，把中文字段改为统一英文名，转换日期和数字，删除重复行；网络失败后读 CSV。
- `src/indicators.py`：计算简单移动平均线和 RSI，并找出 MA 金叉、死叉。
- `src/backtest.py`：把交叉信号后移一天，用下一日开盘价做模拟成交；保存现金、持仓、费用和每天总资产。
- `src/trend.py`：用交易日序号和收盘价学习一条直线，按时间先后分训练集、测试集。
- `src/paper_trading.py`：保存模拟账户和订单。信号 ID 用“股票+日期+方向”防止重复。
- `src/charts.py`：把 DataFrame 转成 Plotly 图。
- `src/utils.py`：日期验证和 CSV 编码等小工具。

## 关键输入与输出

指标函数输入至少含 `close` 的 DataFrame，输出新的 Series 或 DataFrame，不修改原表。回测输入含 `date/open/close`，输出指标字典、资产曲线和交易表。趋势函数输出历史拟合、未来延伸、MAE 和方向。模拟订单函数输入账户、代码、方向、价格，输出一条始终标记为 `is_paper_trade=True` 的记录。

## 核心逻辑

金叉是短期 MA 从长期 MA 下方走到上方；死叉相反。最重要的一点是：今天收盘之后才能知道今天是否交叉，所以不能假装在今天收盘前已经知道答案。代码把信号 `shift(1)`，明天开盘才交易。

RSI 的上涨平均值除以下跌平均值会遇到“除以零”。连续上涨时 RSI 设为 100，完全不变时设为 50，最后限制在 0 到 100。

最大回撤先计算每天之前出现过的最高资产，再看当前资产相对最高点跌了多少，最负的数就是最大回撤。

## 面试怎么说

先讲目标和安全边界，再用“数据—指标—回测—验证”的顺序。重点解释为什么信号延迟一天、为什么测试不访问网络、为什么趋势线不是预测。演示时应主动说出项目局限，而不是只展示好看的结果。
